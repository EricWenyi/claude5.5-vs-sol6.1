# 怎么判断温度计准不准

## 先看标称精度

| | 温度 | 湿度 |
|---|---|---|
| Govee H5075 | ±0.3 °C（±0.54 °F） | ±3% RH |
| AcuRite 01083M（“Pro Accuracy”系列） | ±0.2 °C（±0.5 °F） | ±2% RH |

两台都属于家用里比较准的型号。所以**两台放在一起时，温度相差不超过 0.5 °C、湿度相差不超过 5%，就符合各自的标称精度**。看板“与 AcuRite 对比”里的判断就是按这个标准。

要注意三点：

1. 标称精度是新机在常温、中等湿度下的指标。单台会有个体差异，**湿度传感器用几年后普遍会漂移**，温度一般稳定得多。
2. 两台读数一致，说明大概率都没问题，但不能完全证明（两台可能偏向同一边）。两台读数不一致，只能说明**至少一台**有偏差，看不出是哪一台。要知道谁对，需要一个已知的基准，也就是下面的盐水测试。
3. **放的位置往往比传感器本身影响更大。** 阳光直射、靠近暖气或空调出风口、放在电视或路由器旁边、贴着外墙或窗户，都可能让读数差出好几度。卧室里建议放在内墙一侧、离地 1–1.5 米、远离以上这些地方。

## 第一步：并排对比

1. 把两台并排放在一起，高度相同，避开阳光、出风口和电器，也别放在床头紧挨着人呼吸的地方。
2. **等至少 30 分钟**再读数。刚用手拿过的温度计会被手焐热，需要时间恢复。
3. 打开看板最下方“与 AcuRite 对比”，填入 AcuRite 屏幕上的温度和湿度，点“记录对比”。系统会自动配上同一时刻的 Govee 读数。
4. 在一天里不同时间（早、中、晚）多记几次，看平均差。

怎么看结果：

- 平均差在 ±0.5 °C 和 ±5% 以内：两台一致，正常使用即可。
- 温度一致、湿度差得多：很常见，湿度传感器更容易漂移。做第二步，看是哪一台的问题。
- 温度也差 1 °C 以上：先检查放的位置，再按第三步核对温度。

## 第二步：盐水测试（检验湿度）

饱和食盐水在密闭空间里会把空气湿度稳定在 **75%**（20 °C 时 75.5%，25 °C 时 75.3%），这是家里最容易做的湿度基准。

需要：食盐（普通食用盐即可）、水、一个瓶盖、一个能密封的保鲜袋或密封盒。

1. 瓶盖里装满盐，滴几滴水，搅成**湿沙一样的糊**。盐不能完全溶化，要一直有没化的盐粒。
2. 把瓶盖和两台温度计一起放进袋子，封好。注意别让盐水洒到温度计上。
3. 放在温度稳定的地方（避开阳光和出风口），**至少等 8 小时，放一整夜最好**，等到 12–24 小时更稳。
4. **隔着袋子读数，不要打开**，一开封湿度马上会变。
   - Govee 的蓝牙信号能穿过袋子，看板上的湿度曲线会一路升高，曲线**变平了就说明到平衡了**。
   - AcuRite 直接隔着袋子看屏幕。
5. 计算偏差：**校准偏移 = 75 − 读数**。比如 Govee 显示 72%，偏移就是 +3；显示 78%，偏移是 −3。

怎么看结果：

- 读数在 72–78% 之间（±3%）：在 Govee 标称精度内，可以不校准，想更准也可以按偏移校准。
- 偏差超过 5%：传感器已明显偏离，校准后可以继续用；偏差超过 10% 或读数乱跳，考虑换一台。

两点补充：

- 盐水测试只检验了 75% 这一个点，而卧室平时在 40–50%。想更严谨，可以再用**氯化镁**（药店或网上卖的“镁片 / magnesium chloride flakes”）按同样方法做一次，基准是 **33%**。两次偏差差不多，就用平均值；差得多，就用离卧室日常湿度更近的那次（通常是 33% 那次）。
- 从袋子里拿出来后，湿度传感器可能要几个小时才能回到正常状态，之后再做第一步的对比。

## 第三步：核对温度（可选）

温度一般比湿度准得多，大多数情况下第一步的并排对比就够了。如果想要一个可靠的基准：

1. 找一支带探针的厨房温度计，把探针插进**冰水混合物**（碎冰加水搅匀，冰要多于水），读数应为 **0.0 °C / 32 °F**。偏多少就记下来，这支探针就成了你的基准。
2. 把探针**悬在空气中**，紧挨着两台温度计，别碰到桌面或墙，等 15 分钟以上再比较。
3. 不要把 Govee 或 AcuRite 放进冰水，它们不防水。

## 第四步：把校准写进看板

只有 Govee 的读数会进看板，所以校准的是 Govee：

```bash
python -m bedroom_climate --temp-offset -0.3 --humidity-offset 3
```

- 偏移 = 基准值 − Govee 读数。
- 数据库里存的是原始读数，偏移是在显示时加上去的，所以**改了偏移，历史曲线也会一起修正**。
- Govee App 里的校准设置不影响蓝牙广播（用户反馈如此），所以要在这里设置。
- AcuRite 如果被测出有偏差，看板没法改它的屏幕，在对比时自己心里加减就行。
