导入 / 导出

以前在手机备忘录、Excel 或其他 App 里记过体重，可以导出成 CSV 再导入这里。文件里要有一列日期和一列体重（表头写 date / 日期 和 weight / 体重 即可）；重复的记录会自动跳过，导入两次也不会重复。导出的 CSV 可以直接用 Excel 打开，也是这里的备份。

导出全部记录 (CSV)
“当天”是当天所有读数的平均；“7 天平均”是截至当天最近 7 天的平均。趋势是用最近 28 天每天的读数拟合的直线斜率。
数据保存在运行本程序的电脑上（SQLite 文件），不会上传到任何地方。
